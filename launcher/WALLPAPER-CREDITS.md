# Обои

Встроенные обои (`assets/wallpapers`) - оригинальные картинки, сгенерированные кодом
(`extras/generate-jdm-wallpapers.py`): ночной город, перевал и мост, условный силуэт купе.
Никаких реальных моделей, логотипов и чужих фото. Можно свободно использовать по лицензии проекта (MIT).

Свои обои - через `6-my-wallpapers.bat`.
